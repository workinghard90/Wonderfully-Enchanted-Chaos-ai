    Before you publish

    Print settings: Letter (8.5 × 11 in), scale 100%, margins none, headers and footers off. Artwork fits inside a 7.5 × 10 in area without cropping. Resolution estimates use each image’s fitted size.

    This is a book assembly prototype. Browser printing is not a validated KDP export; inspect the final PDF, page count, margins and image quality yourself. A cover, front matter and KDP checks are not included.

    ZIPs contain the original artwork in the current order and a title/settings manifest. Blank backs are added only to the print layout. Reloading a ZIP is not supported yet.
