# Coloring Book Studio

The prototype from PR #10 now lives in `wec_engine/studio_web/coloring/`, so
there is one packaged version for Windows and the hosted studio. Install the
project and start `wec-studio`, then open **http://127.0.0.1:8765/coloring/**.
The main dashboard also links to it in a new tab.

On an iPhone, use the hosted HTTPS `/coloring/` page in Safari. Opening a downloaded
HTML file in a Files-app preview does not provide a functioning browser app.
See [the workflow and limits](../../docs/COLORING_STUDIO.md).
